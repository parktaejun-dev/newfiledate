개인정보처리방침

최종 개정일: 2026-08-06

1. 파일 처리 방식

본 서비스는 두 가지 모드를 제공하며, 파일 처리 위치가 서로 다릅니다.

모드처리 위치서버 전송
일반 파일 날짜 (OS) 이용자 브라우저 메모리 없음 (100% 로컬 처리)
HWP / PPT 작성일 (Pro) 서비스 서버 (메모리 내 변환) 있음 (처리 후 즉시 폐기)
일반 파일 날짜 모드: 파일이 이용자의 브라우저를 벗어나지 않습니다. 압축 및 날짜 변경이 전부 기기 안에서 이루어지며 서버로 전송되지 않습니다.
Pro 모드: 문서 내부 메타데이터를 수정하려면 파일을 서버로 전송해야 합니다. 전송된 파일은 요청 처리 중에만 메모리에 존재하며, 결과 파일을 반환한 뒤 즉시 폐기됩니다. 디스크나 데이터베이스에 저장하지 않고, 별도로 보관·열람·제3자 제공하지 않습니다.

2. 수집하는 정보

회원가입이 없으며 이름·이메일 등 개인 계정 정보를 수집하지 않습니다.

항목목적보유 기간
업로드 파일 및 파일명 (Pro 모드에 한함) 문서 메타데이터 수정 요청 처리 중에만 메모리에 존재, 응답 후 즉시 폐기
접속 로그 (IP, User-Agent, 요청 시각) 서비스 운영 및 보안 보호 호스팅 사업자(Vercel) 정책에 따름
이용 통계 (페이지뷰, 클릭 통계) 서비스 품질 개선 Google Analytics 정책에 따름 (IP 익명화)

이용 통계에는 파일 내용이나 파일명이 포함되지 않습니다.

3. 쿠키 및 제3자 서비스

본 서비스는 다음 분석 및 웹 호스팅 도구를 사용합니다.

  • Google Analytics 4 — 이용 통계 분석 (IP 익명화 적용).
  • Vercel Analytics / Speed Insights — 웹 성능 및 트래픽 측정.

4. 안전성 확보 조치

  • 전 구간 HTTPS 암호화 전송
  • Pro 모드 업로드 파일의 디스크 저장 없음 (메모리 처리 후 즉시 삭제)
  • 업로드 파일 형식·크기·개수 제한 적용

Privacy Policy

Last updated: 2026-08-06

1. How files are handled

File Date (OS) mode processes files entirely inside your web browser. Nothing is transmitted to any server.

HWP / PPT (Pro) mode sends the document to the server to edit embedded metadata inside it. Uploaded files exist only in server memory for the duration of the request and are immediately discarded after returning the modified ZIP file. They are never written to disk or retained.

2. Information collected

There are no user accounts and we do not collect names or email addresses. Usage statistics never include file names or file contents.

3. Security

  • 100% Encrypted HTTPS transmission
  • No disk storage for uploaded files in memory
  • Strict request payload limits and sanitisation
